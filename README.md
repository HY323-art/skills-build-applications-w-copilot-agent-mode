## Frontend environment setup

The React app expects `VITE_CODESPACE_NAME` to be defined when running in GitHub Codespaces. Add it to a frontend `.env.local` file, for example:

```bash
VITE_CODESPACE_NAME=your-codespace-name
```

When `VITE_CODESPACE_NAME` is unset, the app falls back to `http://localhost:8000` for local development.
